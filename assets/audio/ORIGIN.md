# Original synthesized audio notice

The WAV files in this directory are created by `tools/generate_audio.py`.
They are generated entirely from original note patterns and mathematical
waveforms. No recordings, loops, samples, third-party melodies, or external
audio libraries are used by the generator.

`cover-loop.wav` is the spacious 96 BPM opening loop. `game-loop.wav` uses a
moderate 124 BPM challenge pulse. The feedback and transition sounds are also
generated by the same script. The current set was regenerated on 2026-08-18.

The matching `.mp3` files are compressed delivery copies produced from those
WAV masters. Browsers load the MP3 versions to reduce mobile network transfer;
the WAV files remain the reproducible synthesized masters.

Keep this notice, the generator source, and the generation date with the
event source archive. This provides a clear production record, but it is not
a substitute for a formal legal clearance review for a large commercial or
high-risk public campaign.
